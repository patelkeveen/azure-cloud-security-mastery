# Start Here

Use this repository as an implementation portfolio, not as passive notes.

## First path

1. Read `README.md` for the mission and pillars.
2. Read `MASTERY-STANDARD.md` to understand what counts as done.
3. Read `CURRICULUM-MAP.md` for domain coverage.
4. Pick one vertical slice from `ROADMAP.md`.
5. Create evidence using `EVIDENCE-SCHEMA.md`.
6. Produce customer artifacts from `CUSTOMER-DELIVERY-CATALOG.md`.

## Required daily rhythm

- Learn the official concept.
- Build the smallest useful implementation.
- Record commands, permissions, and expected output.
- Break one dependency on purpose.
- Diagnose from logs, metrics, traces, and admin portals.
- Fix, rollback, or redeploy cleanly.
- Explain the customer value, risk, cost, and support model.

## Honesty rule

Do not say a tool, migration, or workload is mastered until the repo contains personally verified evidence. Research is valuable, but it must be labeled as research.
