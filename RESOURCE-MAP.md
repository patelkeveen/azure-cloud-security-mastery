## Unofficial but useful learning material

These are supplemental explanations and practical viewpoints, not authorities. Verify commands and current product behavior against Microsoft documentation before using them.

- John Savill's Technical Training: deep Azure, identity, networking, security, and architecture explanations.
- Microsoft Mechanics: product demonstrations and feature context.
- Andy Malone / Azure Academy: Azure administration and certification-oriented walkthroughs.
- Practical 365: Microsoft 365, Exchange, Teams, and tenant administration articles.
- Tony Redmond / Office 365 for IT Pros: Microsoft 365 administration and service-change analysis.
- Quest, BitTitan, ShareGate, Cloudiway, and AvePoint technical blogs: migration patterns and product-specific workflows. Treat vendor content as product perspective, not neutral comparison.
- ITPro / CBT Nuggets / Pluralsight / LinkedIn Learning: structured labs and explanations when access is available.
- Azure Friday and Microsoft Reactor recordings: architecture and implementation demonstrations.
- AZ-104, AZ-500, SC-300, and M365 community study groups: useful for practice questions, but validate answers against official objectives and docs.

## Resource verification rule

For each important resource record:

- Date accessed.
- Product version or service state.
- Official source checked.
- Commands tested.
- Tenant/region assumptions.
- Pricing or limits verified.
- What was learned.
- What remains unverified.

Do not copy a blog's claim into a portfolio or resume without reproducing it or verifying it in official documentation.
