# Day 6 — Migration Tooling Ecosystem

## Outcome

Compare native Microsoft tools and third-party tooling without claiming experience you have not obtained.

## Tasks

1. Study Microsoft Migration Manager, Exchange migration methods, SharePoint/OneDrive migration, and cross-tenant mailbox guidance.
2. Research BitTitan MigrationWiz, Quest On Demand, ShareGate, Cloudiway, AvePoint, and Xillio from official vendor material and independent sources.
3. If a trial is available, record tenant, version/state, permissions, source data, setup, output, limitations, error, cleanup, and cost.
4. Compare workload support, identity mapping, permissions, coexistence, delta, throttling, reports, reconciliation, APIs, security, licensing, and escalation.

## Failure exercises

- Missing source permission.
- Mapping mismatch.
- API throttling.
- Unsupported content.
- Partial migration and reconciliation discrepancy.

## Deliverables

Tool matrix, selection ADR, limitations register, mapping template, throttling/backoff guide, and honest verification status.

## Teach-back

Explain when native tools are sufficient, when a specialist tool may help, and why vendor familiarity is not the same as verified hands-on experience.
