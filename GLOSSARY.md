# Glossary

- **AD DS**: Active Directory Domain Services for on-premises identity, Kerberos, LDAP, DNS-integrated domains, and Group Policy.
- **ADFS**: Active Directory Federation Services for federated authentication and claims issuance.
- **Conditional Access**: Entra policy engine that evaluates user, device, app, risk, location, and session conditions.
- **HLD**: High-Level Design describing target architecture, major components, integrations, risks, and decisions.
- **LLD**: Low-Level Design describing implementation-level settings, object names, policies, scripts, and validation.
- **NHI**: Non-human identity such as service principal, managed identity, app registration, automation account, CI/CD identity, AI agent, or workload identity.
- **PIM**: Privileged Identity Management for just-in-time role activation, approval, justification, and audit.
- **RAG**: Retrieval-Augmented Generation, where an AI app retrieves enterprise data and uses it as grounding context.
- **SCIM**: System for Cross-domain Identity Management, commonly used for SaaS provisioning and deprovisioning.
- **Workload identity federation**: Trust pattern that lets a workload exchange an external OIDC token for cloud access without long-lived secrets.
