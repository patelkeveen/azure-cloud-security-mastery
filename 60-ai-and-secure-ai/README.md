# 60 — AI and Secure AI

> ⭐ **What this is:** the **SC-500 bridge** and the newest surface in the field. ⭐ **The organising
> insight: an AI agent is a non-human identity that can be talked into things** — which makes this
> domain an extension of [`../30-identity-and-nhi/`](../30-identity-and-nhi/), not a separate
> subject.

**When to read it:** ⭐ **after SC-300 and SC-200.** ⚠ It is also the domain where being early has
the most career value, because few people can discuss it concretely.

**Prerequisites:** [`../30-identity-and-nhi/`](../30-identity-and-nhi/) Layer 4 (workload
identities) — ⭐ **agent identity is workload identity with a language model attached.**

---

## Why this domain exists

⭐ **Classic security assumes the attacker must find a flaw. Prompt injection means the attacker
just has to write persuasively into data your model will read.** That is a genuinely new class, and
it does not map onto existing controls.

⭐ **The identity question is the one that transfers to your existing skill set:** an agent holds
credentials, calls APIs and acts without a human — ⭐ **so every question you already ask about a
service principal applies, plus one new one: *what can it be persuaded to do?***

⭐ **Frameworks worth naming:** MITRE **ATLAS** for adversarial ML techniques, and the Microsoft
Cloud Security Benchmark's AI controls. ⚠ Verify current versions — this area moves quarterly.

engineer is equipped to spot.
