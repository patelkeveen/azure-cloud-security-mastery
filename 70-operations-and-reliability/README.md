# 70 — Operations and Reliability

> ⭐ **What this is:** the layer that decides whether the controls you built are still working in six
> months. ⭐ **Almost all of it transfers to any employer, any cloud, on-premises or not** — which
> makes it the most portable domain in the repository.

**When to read it:** ⭐ **alongside everything else, not after.** Read
[`azure-monitor`](azure-monitor/) and [`log-analytics`](log-analytics/) **before** your first lab,
because ⭐ **logs capture forward only** and telemetry you did not enable does not exist.

**Prerequisites:** [`../20-azure-platform/`](../20-azure-platform/) for scope and RBAC.

---

## Why this domain exists

⭐ **A control that nobody operates degrades to decoration within one quarter.** That is the same
*"deployed is not enforced"* pattern as report-only Conditional Access and DMARC `p=none` — ⭐
**arriving through the staffing door instead of the configuration door.**

⭐ **And the measurement discipline: averages lie, dashboards lie, and "Completed" is a tool's
opinion.** Most of this domain is learning which number to look at.
