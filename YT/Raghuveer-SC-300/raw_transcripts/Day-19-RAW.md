Automated User Provisioning & De-Provisioning
There are five main methods of identity provisioning:
1. HR Systems of Record → Entra ID (e.g., Workday, SuccessFactors)
2. Active Directory Domain Services → via Entra Connect/Cloud Sync
3. Entra ID → SaaS Applications (Dropbox, Oracle, AWS, GCP, ServiceNow, etc.)
4. Entra ID → On-premise applications via SCIM, SQL, LDAP, etc.
5. Entra ID → Custom provisioning via ECMA Connect

Lifecycle Workflows (Identity Lifecycle Management)
The user identity lifecycle is a crucial aspect of an organization’s security posture.
It is divided into three key stages:
1. Joiner → Onboarding process for new employees
2. Mover → Lateral/Vertical role changes
3. Leaver → Employee offboarding, termination, or voluntary separation
🔹 Automating lifecycle workflows ensure immediate productivity for new employees and secure offboarding for departing users.
