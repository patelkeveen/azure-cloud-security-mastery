# Certification and Market Coverage Map

Certifications are inputs, not the destination. This repo maps Microsoft objectives to customer-delivery capability.

## Microsoft certification baselines

| Track | Repo coverage |
|---|---|
| AZ-900 | Azure concepts, shared responsibility, cloud economics, governance, security, identity, and service categories. |
| SC-900 | Microsoft security, compliance, identity fundamentals, Defender, Purview, and Entra concepts. |
| AI-900 | AI workload fundamentals, responsible AI, Azure AI services, and secure AI design vocabulary. |
| AZ-104 | Azure identity/governance, compute, storage, networking, monitoring, backup, and operations. |
| AZ-500 | Azure security posture, identity controls, networking security, data protection, workload protection, and Defender. |
| SC-300 | Entra workforce identity, authentication, access, workload identities, and governance. |
| SC-200 | Sentinel, Defender XDR, KQL, incident response, hunting, and detection operations. |
| SC-500 / Cloud and AI Security | Cross-domain cloud, AI, identity, data, application, and infrastructure security. |
| AI engineer track | AI app patterns, Azure OpenAI, RAG, agents, evaluation, data boundaries, and identity for AI workloads. |

## Job-market capability clusters

- Microsoft 365 Technical Architect: Exchange, SharePoint, OneDrive, Teams, Groups, tenant architecture, customer leadership, HLD/LLD, SOPs.
- M365 Migration Architect: discovery, coexistence, migration tools, waves, cutover, rollback, reconciliation, hypercare.
- Identity and Hybrid Architect: AD, Entra, Connect, Cloud Sync, ADFS, Okta, federation, SSO, tenant consolidation.
- Azure Security Engineer: Azure platform, RBAC, Policy, Defender, Sentinel, Key Vault, NHI, networking, incident response.
- Secure AI Engineer: AI identity, private access, RAG security, prompt injection defense, data protection, governance, monitoring.

## Mapping requirement

Every certification objective should map to a concept file, lab, failure ticket, customer scenario, and evidence record before being called job-ready.
