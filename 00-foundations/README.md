# 00 — Foundations

> ⭐ **What this is:** the substrate everything else assumes. Not exam content, and not optional —
> these are the seven things that, when missing, make every later topic feel like memorisation.

**When to read it:** ⭐ **first, and only once.** Come back to
[`troubleshooting-method`](troubleshooting-method/) whenever something breaks.

**Prerequisites:** none. This is the floor.

---

## Why this domain exists

⭐ **Every "I can follow the steps but I don't really understand it" gap traces back to one of
these seven.** A JWT is unreadable without base64 and JSON; a broken sync is unfixable without a
hypothesis discipline; a CI failure is unfixable without knowing what a line ending is.

⭐ **The line-ending topic earned its place the hard way** — a two-day red build in this very repo,
caused by CRLF changing measured file sizes. See [`git-and-github`](git-and-github/).
