# 45 — M365 Migration Engineering

> engineer" is a job title; "identity enthusiast" is not.**

**When to read it:** ⭐ after [`../40-microsoft-365-platform/`](../40-microsoft-365-platform/) —

**Prerequisites:** M365 workloads; [`../10-networking/dns`](../10-networking/dns/) for cutover.

---

## Why this domain exists

⭐ **Every failed migration was mis-scoped, not mis-executed.** The arithmetic in
[`discovery-and-assessment`](discovery-and-assessment/) §4 — total size ÷ usable bandwidth ×
throttling — ⭐ **chooses the migration type before anyone has an opinion**, and the item that
overruns is always the one nobody counted.

⭐ **The second theme: "completed" is a tool's opinion.** `BadItemLimit`, SPMT failed-file CSVs and
Gmail label collapse all report success while discarding data — which is why
[`migration-reconciliation`](migration-reconciliation/) exists.
