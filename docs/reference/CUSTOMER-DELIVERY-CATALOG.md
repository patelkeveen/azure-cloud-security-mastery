# Customer Delivery Catalog

## Discovery

- Discovery questionnaire.
- Stakeholder map.
- Business outcomes.
- User and workload inventory.
- Current-state architecture.
- Application and dependency map.
- Data classification.
- Compliance and residency requirements.
- Constraints, assumptions, risks and unknowns.

## Design

- Target-state HLD.
- LLD and configuration details.
- Identity and NHI design.
- Network and data-flow diagrams.
- Decision records and alternatives.
- Security threat model.
- Licensing and cost estimate.
- Reliability, RTO and RPO design.
- Operations and support model.

## Implementation

- Work breakdown.
- Configuration checklist.
- IaC and automation.
- Pilot design.
- Test cases and acceptance criteria.
- Change request.
- Communication plan.
- Cutover runbook.
- Rollback plan.
- Validation and reconciliation.

## Operations and handover

- Operations manual.
- SOPs and runbooks.
- Monitoring and alert catalog.
- Access and escalation matrix.
- Backup and restore procedure.
- DR procedure and test evidence.
- Security and audit evidence.
- User/admin training.
- Hypercare plan.
- Service acceptance.
- Post-implementation review.

## Customer communication

Every case should contain:

- Executive summary.
- Technical summary.
- Weekly status report.
- RAID log: risks, assumptions, issues, dependencies.
- Decision log.
- Incident communication template.
- Customer objection and response notes.
- Handover acceptance criteria.
