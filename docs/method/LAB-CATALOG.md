# Lab Catalog

All labs require setup, verification, cleanup, a command journal, evidence, and at least one deliberate failure.

## Foundations and networking

- Linux users, permissions, processes, logs, services, and networking.
- Windows PowerShell administration and event investigation.
- CIDR/subnetting and packet-flow exercises.
- DNS resolution, split DNS, private DNS, and failure diagnosis.
- TLS certificate inspection, expiry, renewal, and trust failure.
- Azure VNet, subnet, NSG, UDR, peering, VPN, private endpoint, and private DNS.
- Application Gateway, Front Door, Load Balancer, WAF, and health probes.

## Azure platform and IaC

- Subscription/resource-group baseline with tags, budgets, locks, RBAC, and Policy.
- Bicep deployment with what-if, validation, drift, and rollback.
- Terraform module with plan, apply, state, policy check, destroy, and recovery.
- Landing-zone design with management, connectivity, identity, and security boundaries.
- Cost and quota investigation with budget alarm and optimization report.

## Identity and NHI

- Entra users, groups, admin units, authentication, Conditional Access, PIM, and access reviews.
- App registration, enterprise application, delegated/application permissions, consent, and owner review.
- Managed identity to Key Vault with secretless access.
- Service-principal credential inventory, expiry, rotation, and emergency revocation.
- GitHub Actions or Azure DevOps workload identity federation.
- OAuth/OIDC/SAML integration and redirect/token failure diagnosis.
- SCIM provisioning with attribute, mapping, deprovisioning, and retry failures.
- AI agent identity, tool permissions, approval, and audit trail.

## AD and hybrid identity

- AD DS lab with DNS, Kerberos, LDAP, and Group Policy.
- Entra Connect Sync with PHS/PTA comparison and Connect Health.
- Source-anchor, soft-match, hard-match, duplicate-object, and rollback exercises.
- ADFS certificate/claim/endpoint failure.
- Cloud Sync and staging-mode swing migration.
- Hybrid identity coexistence and tenant-consolidation design.
